## 🗂️ The “Google Drive for Code” Cheat Sheet

| GitHub Term | Think of It Like... | What It Means |
|---|---|---|
| **Repository** | Project Folder | The main online folder containing your project files. |
| **Commit** | Save + Sticky Note | Saves your changes and records a short message explaining what changed. |
| **Branch** | Make a Copy / Draft | A separate version where you can experiment without immediately changing the original project. |
| **Pull Request** | Suggesting Mode | A request asking the project owner to review and merge your changes. |
| **Pull / Sync** | Refresh / Download | Gets the latest version of the project from GitHub. |

> **Golden Rule:** Your commit message should explain what you changed.  
> Good: `Add Haziq to guestbook`  
> Not so good: `asdfghjkl`

# 📝 Module 1 Hands-On Challenge

## The Class Guestbook

Your mission is to add yourself to the class guestbook and submit your first Pull Request!

### Step 1: Fork the Repository

Click the **Fork** button at the top right of this page.

A fork creates your own copy of this repository under your GitHub account.

### Step 2: Open the Browser Code Editor

Press the `.` (period) key on your keyboard.

This magically opens **VS Code in your browser** using `github.dev`.

No installation is required!

### Step 3: Edit `guestbook.md`

1. Open `guestbook.md` in the left sidebar.
2. Scroll to the bottom of the table.
3. Add a new row using this format:

```text
| 2 | Your Name | Group Number / SAP or PSP | Your Favourite Food | Your 2050 App Idea |
```

Replace the example information with your own details.

> **Important:** Always add your entry at the bottom of the table. This helps everyone avoid merge conflicts.

### Step 4: Commit and Push Your Change

1. Click the **Source Control** icon on the left.
2. Write a clear Commit Note, for example:

   `Add Haziq to guestbook`

3. Do not use unclear messages such as:

   `asdfghjkl`

4. Click **Commit & Push**.

### Step 5: Submit a Pull Request

1. Return to the original repository page.
2. Click **Contribute**.
3. Select **Open Pull Request**.
4. Add a friendly title and description.
5. Submit your Pull Request.

We will merge selected Pull Requests live on the projector! 🎥
